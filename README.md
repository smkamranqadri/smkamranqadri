## What I’m building

These are some of the projects where I’m currently exploring AI-native product engineering.

### [Hermes HQ](https://github.com/smkamranqadri/hermes-hq)

A mission-control workspace for AI-agent teams — projects, tasks, real agent sessions, reviews, approvals, schedules, and status.

It’s also my live lab for **multi-agent orchestration, context and memory, review loops, human approval gates, and agent failure modes**.

### [Llamaport](https://github.com/smkamranqadri/llamaport)

A macOS app for running and downloading local GGUF models with llama.cpp.

Built around a simple idea: make local models easier to operate without hiding what the system is doing — including visible commands, model checks, health checks, and resumable downloads.

### [KIS Skill](https://github.com/smkamranqadri/kis-skill)

An agent skill for **durable project memory, intent and state tracking, execution discipline, and verification** across coding-agent environments.

It explores the workflow layer around coding agents: how they retain context, understand project state, and verify that work was actually completed.
