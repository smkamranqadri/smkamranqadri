## What I’m building

### [Hermes HQ](https://github.com/smkamranqadri/hermes-hq)
A mission-control workspace for AI-agent teams — projects, tasks, sessions, reviews, approvals, schedules, and status.

It is also my live lab for orchestration, context and memory, review loops, human approval gates, and the failure modes that appear when agents start working together.

### [Llamaport](https://github.com/smkamranqadri/llamaport)
A macOS app for running and downloading local GGUF models with llama.cpp — with visible commands, model checks, health checks, and resumable downloads.

### [KIS Skill](https://github.com/smkamranqadri/kis-skill)
An agent skill for durable project memory, intent and state tracking, execution discipline, and verification across coding-agent environments.
